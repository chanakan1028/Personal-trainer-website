# Bloom Coaching

A single-page bilingual (Thai/English) landing page for a personal training business — hero section, about, training packages, and contact footer.

## Live site

Enable GitHub Pages for this repository (Settings → Pages → Deploy from branch → `main` / root) to serve `index.html` directly.

## Local preview

Open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server
```
